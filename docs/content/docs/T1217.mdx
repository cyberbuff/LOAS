## Description from ATT&CK

Adversaries may enumerate information about browsers to learn more about compromised environments. Data saved by browsers (such as bookmarks, accounts, and browsing history) may reveal a variety of personal information about users (e.g., banking sites, relationships/interests, social media, etc.) as well as details about internal network resources such as servers, tools/dashboards, or other related infrastructure.(Citation: Kaspersky Autofill)

Browser information may also highlight additional targets after an adversary has access to valid credentials, especially [Credentials In Files](https://attack.mitre.org/techniques/T1552/001) associated with logins cached by a browser.

Specific storage locations vary based on platform and/or application, but browser information is typically stored in local files and databases (e.g., `%APPDATA%/Google/Chrome`).(Citation: Chrome Roaming Profiles)

## Tests

### Test #1 - Capture currently opened Safari URL

Adversaries use osascript to gather information about the victim's browsing habits and preferences.

```applescript tab="<Code /> Script"
tell application "safari"
  set curURL to URL in front document
  return curURL
end tell
```
```bash tab="<Terminal /> Execution"
osascript -e 'tell application "safari"' -e 'set curURL to URL in front document' -e 'return curURL' -e 'end tell'
```

### Test #2 - Enumerate all Safari tab URLs

Iterates every Safari window and tab and returns the URL of each open tab, giving a fuller picture of the victim's browsing session than the single front-document URL.

<span className="inline-flex items-center rounded-md bg-yellow-50 px-2 py-1 text-xs font-normal text-yellow-800 ring-1 ring-yellow-600/20 ring-inset">⚠️ TCC Required</span>
```applescript tab="<Code /> Script"
set urlList to {}
tell application "Safari"
  repeat with w in windows
    repeat with t in tabs of w
      set end of urlList to (URL of t)
    end repeat
  end repeat
end tell
return urlList

```
```bash tab="<Terminal /> Execution"
osascript -e 'set urlList to {}' -e 'tell application "Safari"' -e 'repeat with w in windows' -e 'repeat with t in tabs of w' -e 'set end of urlList to (URL of t)' -e 'end repeat' -e 'end repeat' -e 'end tell' -e 'return urlList'
```

### Test #3 - Capture the active Google Chrome tab URL

Returns the URL of the active tab in the front Google Chrome window. Browser hijackers read the current Chrome URL before redirecting search queries to attacker-controlled destinations.

<span className="inline-flex items-center rounded-md bg-yellow-50 px-2 py-1 text-xs font-normal text-yellow-800 ring-1 ring-yellow-600/20 ring-inset">⚠️ TCC Required</span>
```applescript tab="<Code /> Script"
tell application "Google Chrome"
  set curURL to URL of active tab of front window
  return curURL
end tell
```
```bash tab="<Terminal /> Execution"
osascript -e 'tell application "Google Chrome"' -e 'set curURL to URL of active tab of front window' -e 'return curURL' -e 'end tell'
```
